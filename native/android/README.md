# Native Android shell overrides

`android/` is generated by `npx cap add android` and is **not** committed to this
repo, so the native source of truth for our customisations lives here.

## Files

| Source (this repo) | Destination (generated project) |
| --- | --- |
| `native/android/app/src/main/java/app/lovable/mindfulmovement/MainActivity.java` | `android/app/src/main/java/app/lovable/mindfulmovement/MainActivity.java` |

Copy after `cap add android`, and re-copy whenever this file changes:

```bash
cp native/android/app/src/main/java/app/lovable/mindfulmovement/MainActivity.java \
   android/app/src/main/java/app/lovable/mindfulmovement/MainActivity.java
```

(If your `applicationId` differs from `app.lovable.mindfulmovement`, move the file
into the matching package directory and update the `package` declaration.)

## What MainActivity.java does

- Installs a `BridgeWebViewClient` subclass and overrides `onReceivedError`.
- Handles the error **only** when `request.isForMainFrame()` is true, so failed
  images/fonts/API calls never replace the whole app.
- Handles **only** connectivity error codes: `ERROR_HOST_LOOKUP` (DNS /
  `ERR_NAME_NOT_RESOLVED`), `ERROR_CONNECT`, `ERROR_TIMEOUT`, `ERROR_IO`,
  `ERROR_UNKNOWN`, `ERROR_PROXY_AUTHENTICATION`.
- Loads `file:///android_asset/public/index.html` — the bundled
  `capacitor-shell/index.html` that `cap sync` copies into the assets folder.
  That page carries the polished Mindful Movement design and the EN/ES language
  detection.
- Swallows the error so Android's default "Webpage not available" page never
  appears.
- Does **not** override `onReceivedSslError`: certificate errors are still
  enforced by the WebView.
- Tracks `showingOffline` (reset in `onPageStarted` for remote URLs, set in
  `onPageFinished` for `file://`) so a repeated failure cannot loop-reload the
  offline page.

The offline page itself adds retry-loop protection on the web side: auto-retry
uses exponential backoff (3s → 48s), only fires while `navigator.onLine` is
true, retries immediately on the `online` event, and shows a "still no
connection" message if Retry is tapped while offline.

## Required after any change here

```bash
npx cap sync android     # copies capacitor-shell + plugins into android/
npx cap open android     # then Run / build a fresh APK-AAB and reinstall
```

Publishing the Lovable web app does **not** update the native shell — the
`MainActivity` change only reaches a device via a rebuilt and reinstalled app.
